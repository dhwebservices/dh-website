A playable 404 page

1–2 hours

Anyone who hits a broken link on our site gets a little game to play instead of a dead end. It's a small game build, and it goes live once David checks it.

What to do

  1. Open Claude in the DH-Website-New folder. Paste the prompt below.
  2. Play it on your laptop AND your phone. It needs to feel good to play. Tell Claude anything that's too hard, too slow or looks off.
  3. Make sure the normal "back to the homepage" links still work.
Prompt to paste into Claude 
I want a fun 404 page on our company website. The website code is in the DH-Website-New folder on the DH-DEV drive (React + Vite, deployed by Cloudflare Pages).

IMPORTANT RULES:
- First create a new git branch called jack/404-game and work only on that branch.
- NEVER commit to or push to main. main is the live website.
- Don't add new npm packages.
- Don't touch anything about payments, logins, the shop or the server functions folder.

What to build: when someone lands on a page that doesn't exist (src/pages/NotFound.jsx), show a small, playable mini-game above the normal "go home" links. Idea: "You found a dead end." A little character runs along and the player taps or presses space to jump over broken links (little 404 blocks). Score goes up, speed increases slowly. Show the best score (saved in the browser). After a game over, show buttons "Back to the homepage" and "Talk to us about a website".

Must:
- work with keyboard AND touch on phones;
- stay smooth, using one canvas element;
- pause when the tab is hidden;
- use our brand colours (dark #14181A, red #C8102E, off-white #F4F5F3);
- still show the normal 404 text and links for people who don't want to play;
- respect "reduced motion" settings.

When done, run npm run build to check it works, commit, and push the branch (git push -u origin jack/404-game). Cloudflare builds a preview of the branch. Tell me the preview link for a missing page, which should be https://jack-404-game.dh-website-djh.pages.dev/this-page-does-not-exist (it can take 2 minutes to appear).

Cyber Essentials checker

About 2 hours

A free 10-question check on our site. It tells an office whether it's ready for Cyber Essentials, then points them to our IT support. That makes it a real lead tool.

What to do

  1. Open Claude in the DH-Website-New folder. Paste the prompt below.
  2. Make Claude show you where each question comes from on the NCSC website. No made-up rules.
  3. Do the check three times: as a really secure office, as a messy one and as somewhere in between. Do the results make sense?
Prompt to paste into Claude 
I want to add a free "Cyber Essentials readiness checker" to our company website, to bring in small offices that need IT support. The website code is in the DH-Website-New folder on the DH-DEV drive (React + Vite on Cloudflare Pages).

IMPORTANT RULES:
- First create a new git branch called jack/ce-checker and only work on that.
- NEVER commit or push to main (main is the live site).
- No new npm packages. Don't touch payments, logins or the functions folder.

Copy how our existing free tool is built: src/pages/LevyCalculator.jsx, and how it is registered in src/App.jsx (lazyPage, PAGES_BY_SEGMENT and a Route) and in src/lib/seoContent.js (a page entry with title and description), plus the Guides link group in scripts/generate-static-seo.mjs.

Build a new page at /cyber-essentials-checker:
- 10 yes/no/not sure questions, two for each of the 5 Cyber Essentials areas: firewalls, secure configuration, user access control, malware protection, and security update management.
- Base the questions ONLY on the official requirements from the NCSC website (ncsc.gov.uk, "Cyber Essentials: Requirements for IT infrastructure"). Look them up; don't guess. For example, critical updates within 14 days, multi-factor authentication on cloud services, default passwords changed, and unsupported software removed.
- At the end, show a score per area, a plain-English list of what to fix, and a result: "Looks close", "Some work to do" or "Not ready yet".
- Say clearly that this is a quick self-check, not certification, and that certification is done through an IASME certification body.
- Finish with a box: "Want this sorted for you? We look after IT for small offices across Pontypridd, RCT and Cardiff" with a link to /it-support and the phone number 01443 805303.
- Do NOT say DH is Cyber Essentials certified.
- Same look and style as the levy calculator page, and it must work well on a phone.

Then run npm run build, commit, push the branch (git push -u origin jack/ce-checker) and give me the preview link: https://jack-ce-checker.dh-website-djh.pages.dev/cyber-essentials-checker/
